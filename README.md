# Task 3: Modeling and Evaluation

## Project: Titanic Survival Prediction

### Objective
To develop a machine learning classification model that predicts passenger survival using the Titanic dataset.

### Methodology
1. Loaded the prepared Titanic dataset.
2. Separated features and target variables.
3. Split the dataset into training and testing sets (80:20).
4. Performed data preprocessing and categorical encoding.
5. Trained a Logistic Regression model.
6. Generated predictions on test data.
7. Evaluated model performance using accuracy, precision, recall, F1-score, and confusion matrix.

### Model Used
Logistic Regression (Baseline Classification Model).

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

### Limitations
- Limited dataset size.
- Logistic Regression may not capture complex relationships.
- Missing passenger information may affect predictions.
- Model performance depends on the quality of input features.

### Conclusion
The Logistic Regression model successfully established a baseline for Titanic survival prediction. The evaluation metrics helped assess its predictive performance and identify areas for improvement. More advanced algorithms, such as Decision Trees and Random Forest, could be explored to improve predictions.
